## Deploy with GitHub Pages
1. Sign in to GitHub and create a new **public** repository named `it-portfolio` (or another name).
2. Upload `index.html`, `style.css`, and `script.js` to the repository's root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for GitHub Pages to publish. Your URL will look like `https://YOUR-USERNAME.github.io/it-portfolio/`.
7. Open the URL in a private/incognito browser window to test it before submitting it to your LMS.

Note: GitHub Pages publishing may take a few minutes. Do not submit the example URL; use the actual URL shown in your repository's Pages settings.
